# Frise Factory

Application web permettant de créer, personnaliser et exporter des frises chronologiques.

## Publication avec GitHub Pages

1. Créez un dépôt GitHub, par exemple `frise-factory`.
2. Placez directement à la racine du dépôt le contenu de ce dossier.
3. Dans GitHub, ouvrez **Settings > Pages**.
4. Choisissez **Deploy from a branch**, puis la branche `main` et le dossier `/ (root)`.
5. Enregistrez la configuration.

L'application sera alors accessible à une adresse de ce type :

`https://votre-compte.github.io/frise-factory/`

Tous les chemins utilisés par l'application sont relatifs. Le nom du dossier local dans lequel elle a été développée n'apparaît donc pas dans l'adresse publiée.

## Contenu

- `index.html` : page principale
- `styles.css` : mise en forme
- `app.js` : fonctionnement de l'application
- `assets/` : logo et icônes
